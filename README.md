# Dashboard de Producción Industrial

Aplicación desarrollada en Streamlit para analizar indicadores operativos industriales.

## Funcionalidades

- KPIs de producción
- Filtros interactivos
- Visualizaciones con Plotly y Altair
- Tabla dinámica
- Análisis de defectos y productividad

## Librerías utilizadas

- Streamlit
- Pandas
- Plotly
- Altair

## Ejecución local

```bash
streamlit run app.py
```
